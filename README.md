# ELEXE Client

ELEXE is a Minecraft Java Edition client for Fabric 1.21.11.

## Features
- Combat modules
- Movement modules
- Render modules
- Player utilities
- Customizable settings
- Additional client features

## Installation
1. Install Fabric for Minecraft 1.21.11.
2. Download the latest ELEXE `.jar`.
3. Place the file in your `.minecraft/mods` folder.
4. Launch Minecraft with Fabric.

New versions will be released with bug fixes, improvements, and additional features.
